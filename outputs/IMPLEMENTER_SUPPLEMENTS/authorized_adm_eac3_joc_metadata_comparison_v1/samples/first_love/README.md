# First Love.wav — metadata-only receipt

Disposition: `QUIET_WINDOW_NOT_VALID_AUDIO_SAMPLE`. This package contains only the sample receipt, ffprobe/OpenJOC JSON metadata, bounded source-window measurements when applicable, a file manifest, and a verifier. It contains no WAV, EC3, PCM, raw logs, configuration XML, or license material.

DEE completed the selected R138 window and OpenJOC found JOC Addbsi metadata, but DEE measured -120 LUFS with zero sample and true peak. Active program audio is not confirmed, so this is excluded as an active-audio sample.

The OpenJOC classification is based on in-band syntax. FFprobe's Atmos profile is recorded separately. ETSI strict validation failed 33/33 access units while deployed compatibility passed 33/33; rendering was not verified. No PCM decode or playback was performed.
