# Host input to parameter-code 13 static lineage

## Washed static path

The hash-matched host executable contains an ADM/AtmosMezz input route with a file_name property, plus a separate encode_to_atmos_ddp task route. The reader-side adapter sets/initializes/runs AtmosMezz and exposes target metadata. Static evidence in the Atmos plugin separately constructs a DDP/Atmos process owner, selects a per-item descriptor configuration, and passes a local per-item config object into the EmpireEnc wrapper.

On that selected plugin path, a StringListType/map lookup supplies the value that becomes adapter slot 10. The selected code-13 list builder synthesizes a code-13 value from two configuration arguments; it does not copy a recovered host XML element named code 13. In normal mode, the static expectation is (slot10 == 0 ? 11 : 15) plus the count of high-bit-marked U16 records. In a separate special mode, code 13 is the adjusted source count. Code 14 and type-4 are separate values/domains.

The host-side file_name route, the plugin factory, per-item local config, and code-13 producer are individually traced statically. The host reader's Run return object/packet is not joined by pointer or generation token to the plugin process packet. The task route's selection of the plugin factory slot is also not joined. Therefore the report does not establish an end-to-end host-to-encoder runtime object lineage.

## Field and semantic boundaries

The adapter slot-10 selector is an opaque value from a plugin-owned StringListType/map path; its task/XML semantic label remains UNBOUND and must not be called data_rate based on shape or equal numeric values.

The same per-item constructor copies owner+0xF58 into a separate subblock +0x100, while slot10 is derived from subblock +0xD8. Keep the measurement-block and selector fields distinct; adjacency or same parent does not join their values.

The static code-13-to-selected-complexity-byte path is covered by a separate washed supplement. This package does not join code 13 to semantic ID14 object_count + 1. Five scalar vectors are conditional static expectations only; native execution is NOT_RUN.

No codec algorithm or readiness change follows. No PCM, encoded payload, license, or private-key material is included.
