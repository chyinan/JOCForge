## Exact wrappers

In both `deployed_compat` and `etsi_emdf`, ID1 is `sample_offset=null`, `duration=1536`, `group_id=null`, `codec_data_present=false`, `discard_unknown_payload=false`, `payload_frame_aligned=false`; `create_duplicate`, `remove_duplicate`, `priority`, `processing_allowed` are null/unconsumed. Duration is a fixed F13 wrapper input in source-sample units, not a value extracted from ID1 body or timer state. F13 stages the ID1 timer from same-programme completed F06 measurement plus explicit preferred and emits the body each source, including priming. See F13.6–.8, F13JO.2–.3 and `F13-MEASUREMENT-ID1-PROGRAMME-LIFETIME-V1`.

In both modes, ID2 is `sample_offset=null`, `duration=null`, `group_id=null`, `codec_data_present=false`, `discard_unknown_payload=true`, and aligned/duplicate/priority/processing fields are null/unconsumed. F13D2.1–.4 builds its stateless body afresh from the same-writer Type11 header LFE flag and job line/RF profile; selected none maps to0. It is a 21-valid-bit body padded to3 bytes, not an 8-byte fixed body. Body semantics are distinct from the outer wrapper's discard bit.

These explicit nulls mean no corresponding bits are present, not encoded numeric zero. F13.3 reads wrapper fields in order: sample offset presence, duration presence and when present variable unsigned w11/m2, group presence, codec-data presence, discard flag; when discard=false and offset absent read aligned, and only when aligned read duplicate fields plus priority/processing. For selected ID1, duration1536 fits one w11 data group followed by continuation0; aligned is present=false. For selected ID2, discard=true ends conditional config immediately, so no aligned/duplicate/priority/processing bits follow. Do not interpret the first subsequent length bit as an aligned field. F13.9 changes ID11/ID14 only; ID1/ID2 wrappers and bodies remain unchanged, but the entire protected container must be reserialized and revalidated in the selected mode.

## Lengths and distinct admissions

F13.4–.5 FIFO byte capacities are ID11 160, ID1 10, ID2 8, ID14 543; each accepts actual body length 0..capacity at the generic queue boundary, with no truncation. The selected ID11 producer's body must fit160; ID1 generated body must fit10; selected ID2 body is3 bytes within8. The selected F05JL producer has a separate stricter ID14 body cap372 and coefficient scratch cap4344 bits. Therefore a 373-byte ID14 could fit the generic 543-byte FIFO but cannot be accepted as output of this selected F05JL producer; parser admission for the selected four-body provenance path retains that producer bound. A generic EMDF/queue parser should not globally impose 372 on unrelated valid profiles. A 544-byte ID14 exceeds the FIFO itself.

These per-body bounds do not guarantee that their sum fits a complete container. Independently validate actual serialized protected EMDF total length <=511 bytes and F12 carrier/frame-bit budget; never truncate a body or reuse another mode's offsets/CRC. Reject source on invalid identity, selected config, producer capacity, FIFO push, malformed wrapper or container budget and discard staged state under GTC; no partial publication. Source0/1 advance the staged queues but must not construct/parse published EMDF. For source s>=2, order is 11,14,2,1; ID1/ID2 popped writers are s-2, ID14 popped writer s-1.
