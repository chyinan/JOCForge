# Host pcm_to_ddp registry reference boundary

This Wash delta confirms the nine hash-bound Ghidra references to the literal pcm_to_ddp and classifies their role. The category registration maps it to filter:audio; a separate name comparison recognizes it on an existing config object; the remaining references add or query the literal in host lists. None identifies the selected StageRunner registry callback or the concrete config vtable.

The registry callback remains an indirect function pointer selected from a registry entry. The mapping from the pcm_to_ddp name/category to that entry, its factory override, returned ProcessingStage type, and any DDP descriptor writer remain UNBOUND/NO. This package inventories the scoped references; it does not claim the literal has no other roles outside the inspected host image or establish product policy.
