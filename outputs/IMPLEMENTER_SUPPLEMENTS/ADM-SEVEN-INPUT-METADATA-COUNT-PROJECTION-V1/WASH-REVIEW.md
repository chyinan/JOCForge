# Seven authorized ADM metadata count projections

Seven already hash-bound metadata receipts are consistent: six inputs have 36 CHNA physical rows (10 single-entry bed rows plus 26 Objects rows); one has 38 rows (10 bed rows plus 28 Objects rows). No WAV was reopened in this analysis. These are input-only metadata counts, not native K measurements.

The optional projection `K=Objects rows; M=K+10` is conditional on a native-marker-per-object and single-child-partition assumption. It yields numerical M=N for the 36/38 shapes, but that equality does not establish semantic identity or runtime source-list membership. The native K value and child partition remain `NOT_EVALUATED`; the source-to-native row+0 semantic-ID crosswalk is missing.

This is useful as a small multi-ADM parser/metadata vector set, not proof of arbitrary-N native capacity, selected JOC route, or end-to-end output. No algorithm change is authorized by the projection alone.
