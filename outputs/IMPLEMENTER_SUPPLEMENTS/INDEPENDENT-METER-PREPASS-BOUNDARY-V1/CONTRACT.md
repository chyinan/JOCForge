## Required real producers and handoff

1. **Prepared resource→physical PCM and descriptor.** Validate the selected RIFF/ADM/CHNA graph and DBMD against the same resource identity, source extent N (1..2^63−1) and config. For 38-channel PCM24, CHNA track_index 1..38 maps to planar physical row `track_index-1`; CHNA entry order, pack ordinal and semantic key do not reorder audio. With `H=1536`, normal callback g reads `A=min(H,N-cursor)` complete frames; each F32 planar row contains A decoded samples and receives fresh +0 tail to H. Byte address is `payload_offset+(cursor+relative_sample)*114+3*physical_channel`. Decode three bytes as U24LE, subtract 2^24 when bit23 is set, then convert exactly to F32 as signed_value/2^23; zero is positive zero, with no extra gain or dither. Advance cursor by actual A only in the parent commit. `host_input_count=A` and `frontend_samples=1536` are distinct. Decode/read failure, source/hash/extent/route mismatch or partial read produces no committed cursor/root.
2. **Independent frontend/F04A→MeterComponentOutputRows.** F01E normal controls use the same prepared graph, 28 object samplers and physical binding.
