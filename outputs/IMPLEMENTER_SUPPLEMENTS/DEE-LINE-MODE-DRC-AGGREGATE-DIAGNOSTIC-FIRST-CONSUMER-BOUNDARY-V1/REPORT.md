# Line-mode aggregate 首个读取边界

这份增补把一个通用字符串聚合对象的首个读取点限定为诊断格式化。生产函数返回后，紧邻调用接收同一聚合指针，但只使用另一个输出字符串参数和静态版本文本；没有读取聚合内容。随后第一个实际字段读取点检查 +0x18 的容量值，按 inline/heap 规则取字符串，并格式化 +0x20、+0x28、+0x30、+0x38 四个 QWORD。文本带有 “Initializing Composite Item” 前缀，再通过 logger 虚表 +0x20 输出。

这条边没有建立从该聚合对象到 per-frame DRC +0xA0、codec 或 BSI 输入的有类型传递。聚合具体类型、logger owner/generation、运行时值及后续聚合用途仍未闭合；后续用途没有在本包范围内检查。这里不作全局无消费者结论。

来源为 Ghidra 12.2 只读、no-analysis 静态收据。未运行 DEE 或控制作业进程，未读取媒体、PCM、载荷、私钥或许可内容。实现处置：仅记录首个诊断读取，不把它当 DRC 音频效果，也不改算法。
