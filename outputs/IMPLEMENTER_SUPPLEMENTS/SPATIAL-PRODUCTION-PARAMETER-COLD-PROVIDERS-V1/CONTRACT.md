# Selected spatial production parameters and cold providers

Ready scope: parameter identities, generation rules and cold constructor inputs for the approved 48 kHz, 38-channel PCM24, 10-bed/28-object, single-zero-start-event, 1024 kbps profile. Actual dynamic call order and controls are separately specified by the production wiring contracts.

The provider manifest supplies the selected installed48 parameter set. The attached coverage table gives approved source paths for F03 state/target construction, selected geometry/layout/bed generation, spread/gain parameters, diffusion instances and component attenuation/state. These constructors can be implemented from those sources; the clean package's deliberate exclusion of research Python source is not a missing parameter dependency.

P11/P15 semantic generators cover their explicitly supported layout masks and profile conditions. The original 35-record geometry table is not a dependency of these selected generators. The special P15 front-side Y provider is delivered. Obtain the actual layout from the approved profile/configuration producer; do not choose a guessed layout or extend the supported domain.

Spread has the complete 24-value provider and P11 basis. Generate all eleven gains on an admitted object/positive-width/nonquiet call. An absent call is not a fabricated zero gain vector. Diffusion has generated coefficients, the eleven mode/lane pairs, ten 48 kHz constructor values and full per-tail cold state. Activation, inactive deletion and cold reactivation follow the existing F04F lifecycle. Component processing has the eight generated parameters, K64 and full cold state, and advances all required rows/block state under its existing rule.

Cold assignment=-1, marker=0, matrix positive zero and empty writer-set initialize state only. A production matrix must be generated by the current callback's stages. Preserve the approved compact C/d and canonical target-slot D adapter; fixed-capacity storage does not create active rows or a production fallback.

Parent clocks are separate from shared spatial arithmetic. The main F03W root's remaining-cached-drains=4 belongs to its F02 parent. The independent meter bridge uses its F06 three new zero-input drains. Do not copy the main drain counter into the meter just because parameter and cold audio rules are shared. Stage-local histories/indices use their declared zero or unit cold values, with independent owners.

That authorizes implementation of the supplied selected rules; it does not imply local Rust conformance, real ADM cold execution or product acceptance. Keep those downstream validation states accurate without reopening already-resolved parameter availability.

This supplement carries non-secret approved provider references and imposes no new blanket internal-only label. No vendor key is required. It does not supply a zero matrix, zero spread, guessed geometry or synthetic whole-programme output as a substitute for a producer.
