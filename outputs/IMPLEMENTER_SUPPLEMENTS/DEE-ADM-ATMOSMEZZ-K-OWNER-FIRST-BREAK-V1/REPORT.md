## Bound static route

The existing count-to-consumer path derives source descriptor `K` from `U`'s individual/group record containers.

No WAVE `fmt.channels` scalar or CHNA row-array pointer is passed at the StageRunner property/callback edge. The converter-side CHNA owner `C` is not typed-joined to encoder-side `U` or `K`. The K count and row storage therefore cannot be equated to a particular WAVE/CHNA physical row count from this evidence.

Even assuming that source-reference is the intended file, the factory's `U.open(source-reference)` boundary does not establish which parsed WAVE/CHNA rows populate `U`'s record containers. The native static count gate of 1..128 from the related receipt is not universal ADM admission.
