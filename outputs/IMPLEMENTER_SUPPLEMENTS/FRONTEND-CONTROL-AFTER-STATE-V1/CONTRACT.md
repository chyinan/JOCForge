# Frontend control after-state: selected F01E local contract

Grade: approved F01E/GTC and washed normal-snapshot crosswalk, with explicitly marked local serialization decisions. Selected scope is 48 kHz, 38 PCM24 physical input tracks, ten beds, 28 object tracks, one zero-start programme-covering event per object, frame length 1536. Actual N and prepared identities come from the admitted programme.

## Unique owner and complete after-state

GTC `frontend_control` owns immutable normalized config and DBMD binding, event/sampler caches, control snapshots and callback clock. One staged after-state contains:

- `callback_index`, `normal_callbacks`, `remaining_cached_drains`, `phase`; use the existing selected cold constructor. `normal_callbacks` is cold zero; the previously proposed +1-per-successful-normal/hold-on-drain projection is LOCAL_MODEL pending Wash approval, distinct from planned `Q=ceil(N/1536)`.
- `objects[28]`, indexed by local owner ordinal: each has `object_ordinal`, optional runtime `host_channel_index`, optional admitted event cache, `sampler_previous_present` and `sampler_previous_xyz_u32[3]` (F32 bit words). Cold host/event are absent, previous absent and words +0. Store the full admitted event fields required by F01E.7–.9, not just a digest or latest XYZ.
- Optional physical binding: exact TrackUID↔local owner slot, semantic key, physical host and channel-format identity, the ten bed channel-format joins, exactly one semantic LFE host and the ascending `regular37_host_order`. The washed UID-sort allocation is a deterministic local option; an existing explicit bijection may be retained. Ordinal is neither host−10 nor semantic key.
- Optional DBMD identity and per-physical-track table, bound to the same prepared input; immutable normalized configuration with actual N and profile fields. A cold example's N is not a universal programme constant.
- Optional complete `last_control38_snapshot[38][13]` in physical host order and `last_regular37_snapshot[37][13]` in the binding's physical order excluding semantic LFE. Both are absent cold. Their runtime views are tagged `Bed6` and `Object13`: bed first six U32 words are defined, slots 6..12 in the rectangular canonical carrier are local zero padding only and are not a recovered raw bed tail or consumable values. Object13 uses the current sampler result. `regular37[k]` is the same snapshot row selected by `regular37_host_order[k]`, not independently sampled or ordinal-indexed.

## Callback transitions

On NORMAL g, preflight prepared programme/attempt, graph, config, DBMD, all 28 events, mappings, current state and `query=g*1536<N`. Build the processing view in physical-host order while looking up each sampler by its explicit UID→owner mapping. For every object, apply the F01E coordinate/default/clamp rules, initialize absent previous state from current writer XYZ, then execute slot 1 and slot 2 with separate F32 rounding; retain the second result and presence in its own nested record. Generate Object13; preserve Bed6 defined values and approved SourceFlags bed view. Stage the complete physical38 and projected regular37 snapshots together, including a final short input callback. The last padded PCM frame belongs to the reader/source cache; it is not an F01E sampler array.

On CACHED_DRAIN, retain the final normal event, sampler values, DBMD/physical binding and both normal snapshots with their original normal provenance; do not resample ADM time or invent zero controls. The main callback transaction advances its callback/owner generation for each successful drain while the sampled payload origin remains the last normal g. Main's four cached drains and the separate meter's three zero-input drains have different parent clocks.

The frontend leaf returns an immutable complete proposal, not a per-row commit. F03W consumes that proposal's same-callback values once for render/flags/features and stages its own spatial state. GTC commits reader_eof, frontend_control, spatial_control and spatial_audio as one callback root swap after required downstream success. F03W's broad `event_control`/snapshot mentions are a logical projection of the same frontend owner, not authorization for a second mutable sampler or independently stepped control cache. If a concrete serializer duplicates a rectangular view, the local representation must prove it equals the owner snapshot at the same commit; do not infer identity from equal hashes or row counts.

## Encoding, receipts and failure

The selected constructor supplies an exact **cold example** as canonical UTF-8 JSON: lexicographically sorted keys, comma/colon separators, `ensure_ascii=false`, decimal integers and lowercase JSON booleans/null, no trailing bytes. Its documented example preimage is 4402 bytes, SHA-256 `9c943879cd36cb45bc7538346cfdf4f71d0998d8f261f75c135045fcb59870aa`; it includes the example N=6522906 and must not seed arbitrary programmes. The package names nested warm fields and a canonical JSON grammar, but does not supply a complete universal warm preimage/byte layout for every event, DBMD binding and runtime mapping. The exact warm field representation, optional encodings and versioned schema need an explicit LOCAL_MODEL serialization contract; do not label it DEE native ABI or hash a generation-only projection as full state.

Minimal local choice: define one versioned canonical value covering every field above, preserve U32 F32 bit words, stable UID/host association and all snapshot rows with defined-field semantics; reject missing/unknown required data and canonicalize using the approved JSON grammar. Hash the complete bytes with the existing GTC owner hash. The parent-issued owner receipt contains `owner_id`, before generation/hash, after generation/hash, `changed`, `commit_count`, and `transaction_id`, plus same programme/attempt/prepared identity and explicit input/snapshot provenance where required by the normal-snapshot contract. Successful callback after-generation is g+1; callback-produced value/sampling origin is g. These are distinct domains; cached drains preserve normal origin while owner generation advances. No additional digest framework is required.

Any preflight, sampler, downstream or commit failure publishes no partial rows or sampler state and leaves the committed owner bytes/generation unchanged; GTC handles retirement. Full restart destroys prior event/cache/snapshot/binding/DBMD/counters and rebuilds cold for attempt+1. Input-only cases are not expected-state seeds. Real ADM execution, native storage layout and product output remain NOT_RUN.
