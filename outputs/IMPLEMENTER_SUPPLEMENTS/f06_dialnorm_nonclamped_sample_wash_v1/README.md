# F06 DialNorm: one nonclamped native first-AU observation

This package washes one bounded PE reference observation on the user-authorized Human Is Cat ADM/WAVE. The exact input SHA-256 and byte-identical ASCII runtime alias are recorded. The same DEE process loaded the hash-bound DDP Atmos module.

The successful nonclamped attempt logged a measured scalar of -20.665958; the native log did not state units. A parser read exactly seven bytes from the first independent syncframe and observed 48 kHz, six blocks, 4096-byte frame size, and five-bit DialNorm U5=21 (-21 dB) at bit offset 45. Zero payload-body bytes were read, the raw prefix was not retained, and the temporary output was removed.

Under the explicit assumption that the native measured scalar is the approved model's selected_lufs input, the model formula predicts U5=21. This is one conditional match for this input/profile only. A prior washed clamped observation on the same input yielded U5=31 at -33.025146; that is a lower-clamp boundary, not a general native rule. The first nonclamped attempt completed but its output was removed before prefix capture; it contributes no U5 and remains disclosed.

The native unit, general rounding, active-PE conversion, measurement-to-BSI-owner same-generation update, and owner startup-versus-measurement behavior remain open. The package does not establish a keyless production path or prove a general algorithm across ADM files. No raw prefix, EC3, payload, PCM, media, or private license/key contents are included.
