## Exact gap classification

- **Defined; integration/validation remaining:** independent meter leaf construction/state materialization; whole normal+zero-drain meter execution; final getters and immutable receipt admission; shared-analysis DRC consumer; per-source parent commits, resets and fault injection. Do not relabel these as missing native receipts or new numerical parameters.
- **Not in selected DRC contract / not required:** serialized nonzero category5 payload byte layout or a producer turning those bytes into authored DRC override records. The typed selected header is not permission to treat32 bits as a decoded scalar payload. No private key or additional packet schema is needed for the checked DRC path. A newly declared payload-consuming interface would need its exact field/type and separate scope first.
- **Bounded representation/profile issue only if requested:** standalone aggregate serialization follows actual instantiated used leaf owners; fixed GTC count constants do not automatically admit arbitrary N. Neither issue authorizes using the combined fixture hash as runtime state.
- **NOT_RUN:** full standalone Meter/DRC/GTC numeric root execution, actual terminal-meter hash, real ADM metering/finalize, complete statistics/limiter replay here, integrated parent failure injection. No new DLL/native/PCM/AU/secret access occurred.

The checker runs real frozen FIFO constructor/advance functions with their real pure delay dependencies, typed rejections, source-clock/parent-discard metadata, count formulas and exact current receipt/schema checks. It does not model opaque payload bytes or invent measurement scalars/terminal hashes.
