# Secondary transform bank/state erratum

This path-free Wash supplement resolves the model-level F06NR bank selection and owner membership against the approved contracts and the frozen F08 Python model. It does not alter the previously delivered input-only package. Native DLL caller identity is intentionally outside this model-only scope.

F06NR uses the F08 PRIMARY transform algorithm with its own five-lane secondary forward-history owner. F06NI consumes that same F06NR-owned, unquantized primary spectrum after the F06NR positive-zero tail operation. The analysis root's F08 primary and companion histories remain separate owners and neither is aliased to, or advanced by, the F06NR secondary owner. The numeric after-state remains `NOT_RUN` in this erratum.
