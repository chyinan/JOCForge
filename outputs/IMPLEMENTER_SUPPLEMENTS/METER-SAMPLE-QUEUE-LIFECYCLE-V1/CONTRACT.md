# Meter sample queue lifecycle

Internal clarification of existing F06W/WH/OF scheduling, with symbolic identity tests. This supplies an implementable queue/clock boundary, not OAR/DV32/K/peak numerical output and not a complete meter root schema.

For H1536, N>0, normal callbacks A=ceil(N/H), pad the last normal source frame with positive zero. Run exactly three additional callbacks with zero source input; post-OAR/DV32 drain output is not assumed zero. Maintain startup3104, pending0 and processed0. Each normal callback adds H to pending; drains add none. skip=min(startup,H), startup-=skip; valid=min(pending,H-skip). Publish the actual six-row upstream frame slice [skip,skip+valid), then processed+=valid and pending-=valid. This includes padded source extent and is not clipping publication to N.

Append published six-row samples in order to one synchronized six-lane block builder. Retain every unconsumed actual F32 value and a shared fill cursor, not only a count/hash. Consume only complete1024-sample blocks, same identity/order for sample peak, true peak and K/energy. Split consumed block at960-energy-window boundaries under existing F06W arithmetic. The energy partial is accumulated mantissa/exponent and K state, not another raw PCM queue; symbolic energy IDs here only audit consumed provenance.

At a committed callback boundary queue occupancy equals processed-consumed (0..1023 per lane). Keep callback/upstream generation, startup/pending/processed, enqueued/consumed/block counters and all pending values under lifecycle authority. Energy owns its own samples_in_window and six accumulators. Avoid duplicating sample buffers across owners; source association belongs in existing typed receipt/clock bindings. Underlying storage/ring layout may be a minimal local implementation choice if logical order and values are preserved.

After the third drain, finalize reads the last committed numeric meter snapshot. Do not add a1024 block, true-peak/FIR/K flush or a partial960 record; do not clear either tail. Numeric terminal identity is computed before insertion of the final measurement/receipt referencing that identity, avoiding self-reference. The eventual whole-meter schema must include all actual states; the symbolic hash in EXPECTED is NOT a production terminal hash.

The test N9217 has seven normal plus three zero-drain callbacks:10752 published samples/lane,10240 consumed,512 raw pending and640 already-consumed energy-partial samples. Its distinct generation/sample IDs show raw tail [10240,10752) and energy tail [9600,10240) do not overlap. Replacing one pending identity changes the symbolic full-value identity. Real queued samples still require actual upstream amplitude values; IDs must not substitute for them.

Inputs/expected are separated. They test lifecycle/provenance, not numerical DSP reachability or actual ADM. Cold reset reconstructs scheduler, buffers and all numerical owners under existing rules; it does not preserve a prior measurement. No main Type10, cached4-drain semantics or output count can substitute for this independent meter producer.
