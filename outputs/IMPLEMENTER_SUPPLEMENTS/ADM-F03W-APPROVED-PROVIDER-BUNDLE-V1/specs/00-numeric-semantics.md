# N00 数值语义

## N00.1 原语

`F32(w)` 是把无符号 32 位位模式 `w` 解释为 IEEE 754 binary32。`U32(x)` 返回 binary32 的原始位模式，保留零的符号。`R32(x)` 以 round-to-nearest、ties-to-even 把精确数学结果舍入到 binary32。本文 `a⊕b`、`a⊖b`、`a⊗b`、`a⊘b` 分别表示一次 `R32` 加、减、乘、除；每个运算符都是独立舍入点，不能融合或重排。

`W16(z)` 和 `W32(z)` 分别取整数 `z mod 2^16`、`z mod 2^32` 后解释为同位宽二补码有符号整数。`I16`、`I32`、`U16`、`U32` 表示相应整数类型。整数右移若对象有符号则算术右移；无符号对象为逻辑右移。`trunc` 向零取整，`rne_int` 取最近整数且平局取偶，二者不能互换。

`sat[a,b](x)=min(b,max(a,x))`。数组下标从 0 开始，区间 `[a,b)` 不含 b。`||` 表示字节串连接。所有循环的增加方向、比较相等时的分支和状态提交时点以条款为准。

`FMA64(a,b,c)` 是 binary64 融合乘加，一次舍入；普通 binary64 乘法与加法各自舍入。FMA64 只允许用于明确指定的空间角度算法，不允许自动用于普通 codec 的 F32 表达式。

`R64(x)` 以最近偶数把精确结果舍入到IEEE binary64。明确使用F64的NNLS等路线，每个四则运算分别R64，sqrt64为数学平方根的R64结果，保持gradual underflow；不能因为都使用F64而开启未声明FMA。F32转F64先取已舍入F32的精确值，不恢复舍入前实数。

## N00.2 边界

F32 正负零和有限 subnormal 按位保留。只有具体条款要求的 tiny-state 清零可以改变它们。配置、变换与策略的数值域要求有限；无穷、NaN、超出规定数组维度或超出查表范围时返回失败，不外推表项。

各模块的溢出策略分开定义。普通有符号指数和成本原语指定 W16/W32 时必须回绕。非有限值作为致命数值错误；候选不可行与致命错误的阶段分类见 F12.6，不能笼统解释为全局状态回滚。前端原生异常表面和所有未观察配置的行为仍为 `NOT_EVALUATED`，不能宣称与原应用错误码相同。

F32 四则运算遵循 IEEE 754 的 signed-zero 语义：乘除的零符号为输入符号 XOR；最近偶数舍入下，非零值精确相消为 +0，同号两个零相加保留该符号，异号零相加为 +0。减法按翻转右值符号后的加法处理。非零精确结果下溢并舍入成零时保留该结果符号。使用 gradual underflow；这些普通数值原语禁止 FTZ/DAZ，具体 tiny-state 清零另按对应条款执行。

F32 min/max 按条款给定的实参顺序选择；数值相等时默认保留第一个实参的位模式。明确要求后访问项的扫描（例如 F09G.2）覆盖此默认。sat 在范围内及等于边界时保留输入位模式，只在严格越界时换成对应边界。

## N00.3 常量来源

协议数值、行为标量和编译来源表分开列在依赖登记表。本包中标明位模式的行为标量来自研究侧核验，未把它们宣称为新创作的资料。标为未交付的表和生产认证材料不属于可用依赖。

小端是音频和位模式 fixture 的字节序。bitstream 和 EMDF 以每字段最高位先写、字节最高位先读；长度和 CRC16 使用大端。位字段不是按主机整数内存布局直接写出。
