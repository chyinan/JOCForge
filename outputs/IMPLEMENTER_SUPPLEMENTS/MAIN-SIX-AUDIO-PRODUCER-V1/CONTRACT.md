## Receiver arithmetic and output

F04R consumes actual Type10 and target_updates once, with same programme/attempt/transaction/callback binding and complete before-state. It executes: (1) 16 independent scalar preconditioners; (2) install targets, then 48 blocks×16 rows×6 lanes of ordered accumulation; (3) 32-delay, blend32 and first 225 ring; (4) lane3 four-section paired LFE post-filter; (5) QMF analysis on lanes 0/1/2/4/5 and audio mode1 surround delay/FIR/synthesis on lanes4/5; (6) temporal0→1→2, descriptor selection, temporal3, six-lane descriptor ramp; (7) post-S09 32-delay, R32(0.5*sample), second 225 ring, yielding final six. Every documented F32 multiplication/addition/subtraction rounds separately, gradual underflow, no implicit FMA or reordered accumulation.

For each input row/sample, preconditioner computes `a=R32(alpha*x)`, `residual=R32(a-old_scalar)`, `output=R32(clamp(residual,-1,1)*0.25)`, `next_scalar=R32(R32(residual*beta)+old_scalar)`; scalar uses the unclipped residual. At each 256-sample boundary a scalar strictly inside (-tiny,+tiny) becomes +0. For each 32-sample row/lane block, install t but retain before current c/slope/remaining. The F04R.4 magnitude and delta thresholds decide hold, ramp start or snap. For ramp samples j=0..31, `coef=R32(R32(((j+1)/32)*slope)+c)` and `out=R32(R32(coef*x)+old_out)`; after the block c=R32(c+slope), remaining decrements. When remaining is zero, the block uses target t directly. Magnitude-gated state holds, including remaining. The exact comparison/tie rules are in F04R.4.

Each 225 ring clips its finite input by strict comparisons to [-1,1], writes then reads, and advances both indices modulo225; cold write224/read0 yields 224-sample delay. The first 32-delay and N32 blend use separately rounded complementary Q15-generated weights; the second 32-delay precedes the half-scale and second ring. The lane3 paired four-section filter uses the exact 4×5 provider and F04R.6 pair recurrence. QMF's 640-word prototype, mode1 surround FIR/synthesis, selected radix2 FFT/rotation and the temporal exchange state use F04Q/F04QF/F04RB in their exact declared order and R32 boundaries; no identity filter or differently ordered reduction is permitted.

F04D selects descriptor from temporal0..2 output before temporal3, excluding LFE, then applies gain after temporal3. Its threshold127 and 12 receiver scalar words are provider-bound. Gain table j=0..127 is exactly `(32+(j mod 32))*2^floor(j/32)/512`. For the first 256 samples, gain ramps from old current by `(target-current)*2^-8`; the remaining samples use target; next gain is exactly target. Its exact peak/hold/release and comparison/rounding rules are F04D.2–.4. The mathematical threshold candidate differs from the old threshold words in 36 locations and cannot be silently called bit-identical.
