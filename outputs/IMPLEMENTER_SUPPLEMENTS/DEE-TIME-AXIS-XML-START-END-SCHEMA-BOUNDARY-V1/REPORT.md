# XML start/end schema boundary

The hash-bound XSD declares the encode_to_atmos_ddp start and end elements as optional xs:string values. Their schema defaults are first_frame_of_action and end_of_file. These are schema facts only: the XSD is not bound to the executing DEE image, and neither default is evidence of a selected runtime value.

The selected host path observed generic source and target property keys, but did not observe start/end keys or values. The XML elements therefore remain unjoined to a typed owner or setter, plugin sample-range members, and Reader cursor/total fields. The native time_base value and offset/auto interpretation were not captured. Runtime, owner, and generation remain UNBOUND/NOT_RUN.
