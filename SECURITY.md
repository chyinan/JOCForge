# Security policy

Do not report a vulnerability in a public issue. If GitHub Private Vulnerability
Reporting is enabled for this repository, use the repository's Security tab to
submit the report. This repository does not declare a private email mailbox.

Include the affected commit or version, reproduction steps, impact, and a
minimal proof of concept. Redact credentials, private media, and personal
paths. Allow time for a fix before public disclosure.

JOCForge rejects malformed ADM/BW64 input and bounds metadata and PCM frame
allocations. Reports about parser denial of service, unsafe output handling,
command invocation, or provenance leaks are in scope.
