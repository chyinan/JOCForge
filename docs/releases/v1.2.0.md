## Added

- Accept 48 kHz 16-bit ADM BWF in addition to 24-bit PCM, including
  WAVE_FORMAT_EXTENSIBLE PCM and RF64 inputs. When present, declared ADM bit
  depth must match the WAV sample width.
- Read native non-composed jobs from disk without retaining the complete input
  in memory. The browser host can stream input from an OPFS handle.
- Add manual dialnorm to XML jobs. The WebAssembly bridge can produce composed
  Flat 7.1 output and expose its Surround EX and custom stream options.

## Fixed

- Preserve physical CHNA track bindings and combine matching DirectSpeakers
  beds. Accept whitespace around ADM numeric fields and keep contiguous
  object-block boundaries aligned in sample time.
- Honor RF64 RIFF and data sizes independently. Finish very short and composed
  encodes, preserve the streamed WASM topology, and honor staged cancellation.
- Include the final partial programme block in LeqA, honor relative loudness
  cache directories, and preserve XML downmix values in legacy AC-3 cores.
- Refine dialogue and dynamics handling, authored trim handling and the LFE
  transform. Improve error messages for missing input and output paths.

## Scope

- This release does not expand the commercial-device playback guarantees.
  The packages include the CLI; the browser/WASM bridge is tested separately.
