# 状态所有权

权威来源是 `parameters/selected-owner-projection-v1.json`、`specs/00-selected-owner-projection-and-j05.md` 和 GTC。当前 projection 有 7 个 field group、7 个 receipt owner 和 6 个 commit owner。`body_proposals` 是纯值，无 committed state。

Selected overlap projection 不等同于 12 个 GTC programme roots。F14K keyless root 的完整状态现记录在 `IMPLEMENTATION-MAP.json.programme_roots.integrity`，不改变上述 projection 计数。这里的 `codec_and_publication.integrity_receipt` 指 stage 输出，不代表完整 integrity root state。

每个 owner 的 state 都保持私有。跨 owner 只传 immutable input、proposal、staged result 或 receipt。接收者不得反向写生产者 state，也不得重新执行已产生 receipt 的 stage。

F01G candidate `SelectedAdmGraph`/`AdmittedSelectedObjectEvents` 是纯值解析结果，不是第十三个 GTC root 或 committed-state owner。它携带 candidate caller-provided AXML/CHNA hashes、38 个 physical identity rows、candidate single-block event values、bed host join、regular source-index relation和same-candidate parsed DBMD fields；没有 audio/event mutable state、commit、programme reset 或 EOF authority。其 source binding 到 F01E main job 未解决，不能据此覆盖 main programme state。

F06ND's zero-only logical FIFO follows the washed model transition in memory. Its logical record field layout and byte serialization remain `UNBOUND`; no nonzero category-5 payload is produced in the selected profile. This does not create a native DEE parity claim or a separate commit owner.

F06ND persistent statistics, scheduler and logical FIFO state types, plus their frame/callback transition values, do not implement `Clone` or `Copy`. The callback proposal exposes borrowed views and a consuming `into_parts` operation; the FIFO proposal likewise moves its next state out. This prevents copying a staged next-state through these public values, but does not prevent a caller from staging twice against the same borrowed before-state. The F06WH parent remains the only commit authority and is not implemented here.

F14K EOF 只在 source 和 published-AU 计数都达到预期值后成功。它将 generation 加 1，并把 `finalized` 设为 true；不输出 frame 或 stage receipt。此行为属于独立 integrity owner slice，不是 CALLBACK commit。

GTC programme root 只是这 12 个 leaf root 的容器和协调边界，不是额外 leaf owner。Selected overlap projection 仍保持 7 个 field group、7 个 receipt owner label 和 6 个 distinct `commit_owner` label；其中 `none_pure_value` 不属于 committed owner。

## Receipt 与失败不变量

每个 staged/committed owner receipt 至少包含 `owner_id`、`transaction_id`、before/after generation、before/after canonical identity、`changed` 和 `commit_count`。Hash 不能替代完整 after state。

fatal 时丢弃完整 staged root。除 global status 和 fatal receipt 外，committed owner identity 保持不变。programme 进入 `RETIRED`，后续 stage 为 `NOT_RUN`。恢复销毁整个 owner root，增加 attempt，并从 meter programme 起点重新构造所有 cold provider。
