# Selected ID1 metadata timer

The selected F13 metadata owner uses one ID1 timer update per 1,536-sample source call, including the two priming sources. The timer's local canonical field named `counter` represents washed `counter_low_s16`; it remains encoded in the existing local v1 root representation to preserve receipt compatibility. Before decrement, the counter must fit signed 16-bit. Values in `[-512, 512]` decrement with signed-16 wrap. A resulting zero clears the caller flag; a nonzero power-of-two magnitude sets it; all other results preserve it. Values outside the decrement interval are preserved.

Each call subtracts the supplied sample hop from all six remaining values, updates the six cached fields, and returns the complete next state and nine-field config together. In mode 1 it writes the output sentinels, skips refresh when the resulting caller flag is set, and otherwise refreshes at most one expired timer using the specified priority. The existing F13 owner uses the selected 1,536-sample hop and the counter-disabled caller input for its fixed current path. The general counter-enabled serializer remains unqualified.

The serializer consumes the produced config and emits the selected ID1 body. The model matches 17 hash-bound primitive state/config/flag cases and 40 sequential timer/config/body observations. The four washed wrapper pre-validation cases are not represented as this timer primitive's tests. The fixture provenance binds the files to manifest `521cea92f4a9a45f0c084d7b78d5699567b2f8c6eb92bd1076ce60079df1a6b7`; the Wash handoff check is `59188e86ee8e75fb1d3c9fb795b6877f7a4e0baf841d84324667421bfd8558ac`.

The observed constructor values `counter_extra_u16=0`, `group_s16=-1`, and `codec_s16=-1` are recorded as fixed constructor scalars; the selected timer never changes or consumes them, so they are not independent mutable root fields. The same-owner constructor reinitialization is observed, but automatic programme reset is not. External measurement production, general counter-enabled ID1 serialization, parent-wide rollback, global callback commit, EOF/reset integration, full ADM-to-AU execution, and product acceptance remain open.
