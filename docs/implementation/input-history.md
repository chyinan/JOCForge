# F07.1 输入历史块转移

本切片实现单通道的一次 F07.1 块转移。`InputHistory::cold` 创建 1,280 个正零位模式。`advance_block` 返回旧历史 `[256,512)`，并将历史左移 256 项，再追加当前 256 项。

helper 只复制 `U32` 位模式，不解释 `F32` 数值。调用方按自己的时钟顺序处理六路和六个块。该模块不验证整帧、不提交 programme owner，也不运行瞬态滤波或 F08 变换。

定向测试按两帧、六路数据重建 `U-HISTORY-01`。测试比较完整 delayed-output 文件和六路终态历史文件。测试还确认首个 1,024 个输出样本为正零位模式，并检查单块转移保留输入位模式。
